# Mira Fragrance theme

Clean, white, mobile-first Online Store 2.0 theme. No libraries; about 60 lines of JS.

- Add a product in Shopify admin and it appears in the **Perfumes** collection automatically
  (make Perfumes an *automated* collection, e.g. "Product type is Perfume", or "Price is greater than 0" for everything).
- Hero image, logo, WhatsApp number and social links are set in the theme editor (Customize).
- Page text for About, Contact, Shipping & Returns, Terms and Privacy is in `../mira-fragrance-pages/`
  (items marked `[TO CONFIRM]` need your facts before publishing).

Preview: `shopify theme dev --path mira-fragrance` (or upload as an unpublished theme).
