# Mira Minimal — Shopify theme

Minimal, light theme for **Mira Fragrance** (logo + hero image included in `assets/`).

## Install
```bash
cd mira-minimal && zip -r ../mira-minimal.zip . -x "README.md"
```
Shopify admin → Online Store → Themes → Add theme → Upload zip file → Publish.

## Setup
- Menus: create `main-menu` and `footer` in Navigation (or pick others in the Header/Footer sections).
- Home page: in the theme editor choose a collection for "Featured products".
- Hero text and button are editable in the Hero section.
